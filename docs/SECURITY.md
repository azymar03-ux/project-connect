## New threat boundaries
Export is a repeatable-read **snapshot**: memberships/metadata are evaluated at snapshot time and immutable source bytes pinned. Later project edits/member removal do not retroactively rewrite the saved snapshot. Account suspension/sign-out prevents publication/download; an already transmitted byte cannot be recalled. Files must be the requesting user's uploads with membership at snapshot; no arbitrary caller ZIP paths or object keys. Snapshot has explicit size/time fail states, not unlimited work. Queue bound is not an independent abuse certification. Scanner is protocol-tested only; clean means scanner result, not proof code is safe to execute. Code downloads remain inert attachments. Do not import executable HTML/archives. Dollar ceiling enforcement relies on an approved rate covering the chosen model and provider adhering to request limits; unexpected provider billing/usage requires separate reconciliation/alert response.
